Project overview

This collection of FPGA work explores how digital behavior is described, simulated, synthesized, and brought out to physical hardware. I used the Digilent Cmod A7-35T development board to investigate clocked logic, finite-state machines, arithmetic datapaths, and peripheral interfaces.

The latest hardware exercise is an ST7789V-based SPI display interface, with the immediate goal of drawing simple Pong-style paddles on the TFT. The initial display bring-up produced two bars successfully; orientation and screen coordinate mapping remain areas for further refinement.

SPI TFT display bring-up

The screen exposes a serial data input and clock alongside control lines for chip select, data/command selection, reset, and backlight. I developed a VHDL-driven interface to send initialization and pixel commands to the controller.

Rather than beginning with a full game engine, the test image uses two simple vertical or horizontal paddles to validate communication, drawing coordinates, and display orientation. This provides a small, observable hardware test before adding input handling and motion logic.

Supporting digital design exercises

Four-bit ripple-carry adder

Described arithmetic logic in VHDL and verified how carry propagates between bit stages using simulation.

Finite-state-machine design

Built and tested state-based control logic, including a vending-machine controller with defined inputs, state transitions, and timeout behavior.

Clock and timing

Worked with board constraints, clock division, and the relationship between synchronous RTL and hardware output timing.

Verification workflow

Used simulation and on-board testing to compare expected state transitions and output behavior against actual implementation.

Next steps

The next iteration is to formalize display orientation settings, separate reusable SPI transport logic from the drawing controller, and move toward animated paddles and game-state logic. Hardware photographs, simulation waveforms, and a source repository can be added as they are organized for publication.
