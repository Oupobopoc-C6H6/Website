One sensing concept, two applications

SunScream was developed through two separate engineering course projects at the University of South Florida. Both use a GUVA-series UV sensor, but they are not two modes of one finished device. The hardware platforms, interfaces, and firmware differ.

UV exposure monitor

The ESP32-based implementation sampled the UV sensor, used an empirical relationship to estimate UV conditions, accumulated an exposure estimate over time, and sounded a buzzer when an experimental threshold was exceeded. Readings were sent wirelessly to an Android Bluetooth serial terminal.

Sunscreen comparison interface

The ATmega328P implementation supplied UV sensor measurements to a Python/Tkinter desktop application over serial. The user recorded an initial baseline, then a sunscreen-treated sample measurement; the interface calculated the relative reduction in sensor response.

ESP32 wireless exposure monitor

This version integrates an ESP32-WROOM-32, GUVA-S12SD UV sensor, and an active buzzer. Firmware samples an ADC input, applies the calibration relationship developed during testing, and accumulates an estimated exposure value at regular intervals.

The device transmits measurement and accumulation values using Bluetooth Serial. The buzzer provides an audible warning after the accumulated estimate crosses a fixed experimental threshold. Outdoor characterization also explored how ADC measurements related to reported UV Index values.

Work in the repository includes embedded firmware, mechanical CAD, circuit design files, and the engineering team report. The published design is a prototype rather than a calibrated personal-exposure instrument.

ATmega328P sunscreen analyzer

The second implementation uses an ATmega328P to read the UV sensor and respond to measurement requests from a Python desktop application. The Tkinter GUI displays the baseline and experimental readings and their relative percentage difference.

The desktop software sends a serial request, receives a numeric sensor reading, and compares the second reading to the baseline:

UV signal reduction (%) =
    (1 - test_reading / baseline_reading) * 100

Alongside the Python GUI, the repository includes microcontroller firmware and KiCad PCB files. This version does not incorporate the ESP32's Bluetooth alarm functionality.

Testing and limitations

The UV exposure implementation uses an empirical sensor calibration, and the project documentation notes substantial variability in outdoor measurements, particularly at low reported UV Index values. The accumulated reading is therefore an experimental estimate rather than a validated UV dose.

The desktop application's percentage is a relative measured signal reduction, not a certified sunscreen SPF rating. The preserved GUI implementation also has practical limitations, including a hard-coded serial port and single-measurement comparisons without uncertainty estimates.

Together, these builds demonstrate sensor interfacing, ADC acquisition, embedded firmware, Bluetooth communication, serial protocols, Python GUI development, and documenting the difference between a working prototype and a calibrated instrument.

Project files

The GitHub repository contains source code and engineering resources for both builds, including the ESP32 firmware and CAD, the ATmega328P firmware and PCB design, the Python GUI, and supporting documentation.
